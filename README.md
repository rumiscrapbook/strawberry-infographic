# 🍓 Strawberry Infographic

A small Canva project about the **benefits of strawberries**.

I created this infographic to practice my Canva design skills while learning and presenting a few health benefits of strawberries in a simple, visual way.

* Boosts immunity
* Supports heart health
* Aids digestion
* Supports healthy skin

## 🎨 Made With

* Canva

This was a personal project created to improve my **graphic design and Canva skills** while turning simple information into a visually appealing infographic.
